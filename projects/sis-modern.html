Tufts SIS Modern

Updating a familiar student tool without replacing how it works.

Interface design · CSS · Stylus

The problem

Tufts’ student information system runs on PeopleSoft. I designed a visual modernization layer for the legacy interface while preserving its existing behavior and navigation.

The constraint shaped the project: improve presentation through a reversible styling layer.

The design

The architecture separates core design tokens from modules for navigation, dashboards, tables, forms, dark mode, and experimental changes.

Key decisions

  • Keep shared styling in core tokens rather than repeat definitions across individual screens.
  • Separate interface areas into modules so changes remain localized.
  • Keep experimental styles separate from the core presentation layer.

Scope & limits

The styling layer leaves PeopleSoft’s application logic and navigation in place. It can change how the interface looks, but cannot change the underlying application’s behavior.

The architecture diagram describes the design; it does not establish a measured improvement in usability or performance.
