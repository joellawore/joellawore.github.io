Readability classification

The most useful result was finding a flaw in the evaluation.

Machine learning · Python · scikit-learn · Course project

The task

Classify literary passages into two reading-level groups using the text and computed readability and stylometric features.

The model

The final pipeline combined character-level 3–5-gram TF-IDF with 28 numerical features. I standardized the numeric branch and trained logistic regression.

The text and numerical branches provided two representations of each passage: character patterns and explicit readability and style measurements.

The evaluation

Ordinary 10-fold cross-validation produced a mean AUROC of about 0.82. On inspection, passages from the same book could appear in both training and validation folds.

That overlap made the estimate optimistic: the model could partly recognize a work it had already seen instead of generalizing to an unfamiliar work.

What changed

I rebuilt validation around groups defined by author and title. The grouped scores were lower and more variable, but provided a more defensible evaluation.

The approximately 0.82 AUROC reflects the original evaluation’s same-book leakage. It should not be treated as performance on unseen works. No aggregate grouped score is reported here.
