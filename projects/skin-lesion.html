Skin-lesion classification

Combining image features and metadata while checking who the model works for.

Machine learning · Python · Gradient boosting · Course project

The data

The task was to predict a binary skin-lesion target from patient metadata and smartphone images. The training set contained 1,178 examples, with 92.4% in the positive class.

The features

I combined 55 processed tabular features with 52 engineered image features: channel statistics, center-versus-border color, symmetry, grayscale and texture proxies, and coarse RGB histograms.

Evaluation

Patient ID defined the cross-validation groups so the same patient could not appear in both training and validation folds. I used balanced training weights and searched 120 HistGradientBoosting configurations.

Model selection considered both overall AUROC and the weakest age-group AUROC.

Limitations

These are cross-validation results from an imbalanced course dataset. They do not establish clinical effectiveness or performance on an external patient population. The gap between overall and minimum age-group AUROC also matters when interpreting the result.
